  Title : Heart Disease Prediction


  1. Task Objective

    The goal of this project is to develop a Binary Classification Model to identify individuals at high risk for heart disease. The project focuses on:

  *Transforming raw clinical data into a machine-learning-ready format using One-Hot Encoding.

  *Building a predictive system that can distinguish between "Healthy" and "At Risk" patients.

  *Evaluating model performance using specialized medical diagnostic metrics like the ROC Curve and Confusion Matrix.

  
  2. Dataset Used

   The project utilizes the UCI Heart Disease Dataset, which consists of clinical parameters from patients.

  *Source: UCI Machine Learning Repository (via Google Storage URL).

  *Key Features (Predictors):

  *Numerical: Age, Resting Blood Pressure (trestbps), Cholesterol (chol), and Max Heart Rate (thalach).

  *Categorical (Encoded): Chest Pain Type (cp), Sex, Fasting Blood Sugar (fbs), and Exercise-Induced Angina (exang).

  *Target Variable: target (0 = No Heart Disease, 1 = Presence of Heart Disease).

  
 3. Models Applied

  The script follows a structured machine learning pipeline:

  *Preprocessing: Uses pd.get_dummies for One-Hot Encoding to convert categorical text/integer data into binary columns, allowing the mathematical model to interpret non-numerical features.

  *Logistic Regression: A statistical model that uses the Sigmoid Function to output a probability between 0 and 1. It is highly effective for clinical settings due to its interpretability.
  *Data Splitting: Employs an 80/20 Train-Test Split to ensure the model is tested on unseen data to prevent overfitting.

 
 4. Key Results and Findings

  Based on the evaluation metrics generated by the code:

  *Model Reliability (AUC): The ROC Curve and the resulting AUC (Area Under the Curve) score indicate how well the model separates the two classes. An AUC closer to 1.0 suggests an excellent diagnostic tool.

  *Confusion Matrix Insights: This matrix reveals the model's "Sensitivity." In heart disease prediction, the most important factor is minimizing False Negatives (patients who have the disease but were predicted as healthy).

  *Impact of Categorical Features: By using One-Hot Encoding, the model can identify which specific types of chest pain or heart rate fluctuations have the highest correlation with cardiac risk.

  *Accuracy: The final Accuracy Score provides a general overview of how many total predictions (both healthy and at-risk) the model got correct.
